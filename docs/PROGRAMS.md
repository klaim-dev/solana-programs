# Program Catalog

Planned Anchor programs:

- `counter`: account initialization and mutation
- `vault`: PDA authority, deposits, withdrawals
- `todo`: account modeling and Anchor tests
- `token_factory`: SPL token creation and minting
- `tip_jar`: transfers and signer constraints
- `airdrop`: controlled distribution
- `cpi_*`: cross-program invocation patterns
- `staking`: reward accounting
- `token_2022`: Token-2022 extensions
- `fee_vault`: fee collection and treasury logic
